| Field | Value |

---

## Method

Studied world-class identity systems as **systems** (mark + type + color + voice + behavior), not as logo galleries. For each: personality, emotional response, logo philosophy, typography, simplicity, memorability, scalability, timelessness — then the transferable **principle**.

---

## Company benchmarks

### Apple
| Lens | Observation |
|---|---|
| Personality | Calm confidence; premium restraint; human-centered technology |
| Emotion | Desire + trust + belonging to a worldview of simplicity |
| Logo philosophy | Single silhouette; decades of continuity; product *is* identity |
| Typography | Sparse, precise, hierarchical; words earn their place |
| Simplicity | Subtraction as strategy |
| Memorability | Instant; almost muscle memory |
| Scalability | Works from favicon to stage |
| Timelessness | Refines rather than reinvents |

**Principle:** *Identity is a living system of restraint. Continuity builds equity.*

### Nike
| Lens | Observation |
|---|---|
| Personality | Motion, courage, determination |
| Emotion | Aspiration to act |
| Logo philosophy | One gesture (swoosh) = attitude; not a picture of a shoe |
| Typography | Bold when needed; secondary to symbol + slogan worldview |
| Simplicity | Extreme reduction to a verb-shape |
| Memorability | Near-universal recognition |
| Scalability | Embroidery to stadium |
| Timelessness | Attitude outlasts campaigns |

**Principle:** *A mark can encode a worldview, not a category.*

### Airbnb
| Lens | Observation |
|---|---|

| Emotion | “I belong anywhere” |

| Scalability | App icon to city keys |
| Timelessness | Purpose-led; can expand beyond “rooms” |

**Principle:** *Higher purpose unlocks a symbol that transcends the product category.*

## Extracted principles for TalkForge (binding for later phases)

| ID | Principle |
|---|---|
| P1 | **System > mark** — logo is one node in recognition, trust, memory |
| P2 | **Purpose before category** — don’t look like “an AI app”; look like TalkForge |
| P3 | **Worldview in one silhouette** — encode practice / voice / transformation without literal mic/chat/brain |
| P4 | **Restraint earns premium** — subtraction > decoration |
| P5 | **Drawable & scalable** — favicon → billboard → emboss → stage |
| P6 | **Emotion in three seconds** — dignity, courage, hope — never shame or hype |
| P7 | **Continuity over novelty** — refine for decades |
| P8 | **Craft as trust** — serious about human moments |
| P9 | **Reject AI clichés** — no sparkles, robots, waveforms-as-logo, chat bubbles |
| P10 | **Explore before converge** — do not marry the first solution |
