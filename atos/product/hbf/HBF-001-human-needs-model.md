## Purpose

Describe fundamental human needs most relevant to **communication** — so TalkForge can interpret behavior as attempts to satisfy needs in context, not as isolated skill deficits.

---

## Needs (minimum set)

### 1. Connection

| Field | Content |
|---|---|
| **Definition** | The need to belong, be understood, and maintain valued relationships |
| **Communication relevance** | Much speech aims to preserve or repair bonds, not to “win” clarity |
| **Typical contexts** | Relationships, friendship, family, community, team |
| **Associated friction** | Loneliness, fear of rejection, avoidance, shame |
| **Evidence level** | **Established Research** — relatedness (Self-Determination Theory); belonging literature |
| **Known limitations** | “Connection” can mask unhealthy dependency; culture varies |
| **Open questions** | Q-HBF-N01 — Which connection signals predict transfer after practice? |

### 2. Competence

| Field | Content |
|---|---|
| **Definition** | The need to feel effective and capable in valued domains |
| **Communication relevance** | People avoid conversations that threaten perceived competence |
| **Typical contexts** | Career, leadership, education, personal growth |
| **Associated friction** | Self-doubt, perfectionism, embarrassment, social comparison |
| **Evidence level** | **Established Research** — competence need (SDT); self-efficacy (Bandura) |
| **Known limitations** | Felt competence ≠ actual skill; confidence/competence diverge (see HBF-005) |
| **Open questions** | Q-HBF-N02 — How should coaching separate felt competence from demonstrated skill without shaming? |

### 3. Autonomy

| Field | Content |
|---|---|
| **Definition** | The need to experience choice and ownership over one’s actions |
| **Communication relevance** | Prescriptive coaching can backfire; agency is the product |
| **Typical contexts** | Career, health, personal growth, leadership |
| **Associated friction** | Resistance, avoidance, resentment of “being fixed” |
| **Evidence level** | **Established Research** — autonomy need (SDT); motivational interviewing stance |
| **Known limitations** | Autonomy support ≠ absence of structure |
| **Open questions** | Q-HBF-N03 — Which TalkForge UX patterns best preserve autonomy under time pressure? |

### 4. Respect

| Field | Content |
|---|---|
| **Definition** | The need to be treated as worthy of consideration; dignity recognized |
| **Communication relevance** | Perceived disrespect collapses listening and trust |
| **Typical contexts** | Leadership, career, education, community, health |
| **Associated friction** | Shame, defensiveness, withdrawal, escalation |
| **Evidence level** | **Established Research** (face/politeness; dignity) + **Internal Evidence** sparse + **AMD-001 binding** |
| **Known limitations** | Respect norms are culturally contingent |
| **Open questions** | Q-HBF-N04 — How do users signal felt disrespect inside voice sessions? |

### 5. Purpose

| Field | Content |
|---|---|
| **Definition** | The need for meaning — that effort connects to something that matters |
| **Communication relevance** | Practice sticks when tied to a real moment that matters |
| **Typical contexts** | Leadership, parenting, career, personal growth, community |
| **Associated friction** | Overwhelm, regret, emptiness, “why bother” |
| **Evidence level** | **Established Research** (meaning/purpose literature) · **Working Hypothesis** for TalkForge measurement |
| **Known limitations** | Purpose is slower to observe than session metrics |
| **Open questions** | Q-HBF-N05 — Can we detect purpose-alignment from intent capture without over-asking? |

---

## Inquiry close

| Lens | Content |
|---|---|
| **Know** | Autonomy, competence, relatedness are established motivational needs; dignity/respect is institutionally binding (AMD) |
| **Believe** | These five needs are a sufficient Phase I lens for communication-relevant design |
| **Uncertain** | Whether additional needs (safety, fairness, status) must be first-class for our users |
| **Would change us** | Repeated internal evidence that coaching fails when a sixth need is unmet; or that one of the five is inert |

**Research roadmap:** Map session intents → needs; tag friction events; validate against outcomes (HBF-006).
