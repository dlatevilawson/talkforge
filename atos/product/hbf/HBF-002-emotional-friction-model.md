## Purpose

Document emotional states that interfere with effective communication — so TalkForge can recognize friction, protect dignity, and design practice that reduces avoidance rather than amplifying shame.

---

## Friction catalog (Phase I)

For each: observed behaviors · communication impact · evidence · research support · potential interventions · open questions.

### Fear

| Field | Content |
|---|---|
| **Observed behaviors** | Delay, over-rehearsal, topic avoidance, truncated answers |
| **Communication impact** | Reduced candor; premature exit from hard moments |
| **Evidence level** | Established Research · Working Hypothesis (product) |
| **Research support** | Anxiety/avoidance; threat appraisal |
| **Potential interventions** | Smaller reps; dignity-preserving stakes; preparedness framing |
| **Open questions** | Q-HBF-F01 — Which voice-UX cues reduce fear without infantilizing? |

### Uncertainty

| Field | Content |
|---|---|
| **Observed behaviors** | Hedging, questions-as-shields, freezing |
| **Communication impact** | Clarity collapses; decision delay |
| **Evidence level** | Established Research · Working Hypothesis |
| **Research support** | Ambiguity aversion; need for cognitive closure |
| **Potential interventions** | Structure the moment; name unknowns; choice architecture |
| **Open questions** | Q-HBF-F02 — Does intent capture reduce uncertainty before first practice? |

### Embarrassment / Shame

| Field | Content |
|---|---|
| **Observed behaviors** | Minimizing, joking away, quitting after “mistake,” hiding struggle |
| **Communication impact** | Learning stops; self-protection dominates |
| **Evidence level** | Established Research · **AMD critical** |
| **Research support** | Shame vs guilt distinction; face threat |
| **Potential interventions** | Normalize struggle; never score the soul; private practice; Respect Standard |
| **Open questions** | Q-HBF-F03 — Which coach phrases correlate with post-error re-engagement? |

### Perfectionism

| Field | Content |
|---|---|
| **Observed behaviors** | Endless prep, refusal to ship a “good enough” conversation, harsh self-critique |
| **Communication impact** | Avoidance of real moments; brittle confidence |
| **Evidence level** | Established Research · Working Hypothesis |
| **Research support** | Perfectionism / performance anxiety literature |
| **Potential interventions** | Progress over polish; transfer goals; time-boxed reps |
| **Open questions** | Q-HBF-F04 — Can we detect perfectionism from session retry patterns? |

### Avoidance

| Field | Content |
|---|---|
| **Observed behaviors** | Skipping hard scenarios; switching to safe topics; postponing invites |
| **Communication impact** | No transfer; false progress on easy paths |
| **Evidence level** | Established Research · Internal Evidence (beta invite gates related) |
| **Research support** | Experiential avoidance |
| **Potential interventions** | Graduated exposure; purpose tethering; autonomy-supportive challenge |
| **Open questions** | Q-HBF-F05 — What is the minimum hard-moment dose for transfer? |

### Overwhelm

| Field | Content |
|---|---|
| **Observed behaviors** | Cognitive blanking, multitask chatter, session abandonment |
| **Communication impact** | Working memory overload; poor listening |
| **Evidence level** | Established Research |
| **Research support** | Cognitive load theory |
| **Potential interventions** | One job per turn; shorter sessions; simplify UI chrome |
| **Open questions** | Q-HBF-F06 — Session length vs overwhelm in voice-first practice |

### Regret

| Field | Content |
|---|---|
| **Observed behaviors** | Rumination on past conversations; “I should have said…” |
| **Communication impact** | Past-focused; blocks preparation for next moment |
| **Evidence level** | Working Hypothesis |
| **Research support** | Counterfactual thinking; regret regulation |
| **Potential interventions** | Rehearse the *next* moment; extract one lesson; close the loop |
| **Open questions** | Q-HBF-F07 — Does post-session reflection reduce or amplify regret? |

| Field | Content |

### Social comparison / Self-doubt

| Field | Content |
