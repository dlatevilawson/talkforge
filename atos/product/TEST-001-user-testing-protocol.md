## Purpose

Validate with real users. Record findings in Research Library + Blind Spot Register.

## Measures

| Measure | Question | Capture |
|---|---|---|
| Trust | Do you trust Forge’s memory and advice? | 1–5 + why |
| Clarity | Was the next step clear? | 1–5 |
| Engagement | Did you want to continue for the right reasons? | Qualitative |
| Confidence | Do you feel more ready for a real conversation? | 1–5 |
| Learning | What did you learn? | Open |
| Readiness | Was this the right conversation now? | 1–5 |
| Retention | Would you return tomorrow? | Yes/No + why |

## Dignity gate

Any session that leaves the user feeling diminished fails Article IX — record as BS + block ship.
