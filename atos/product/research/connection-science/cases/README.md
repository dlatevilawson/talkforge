## Adding a case

1. Copy the blank form from ch.4 template.  
2. Save as `CASE-XXX-<slug>.md`.  
3. Fill sections 1–11 + Inquiry close.  
4. Add a row here.  
5. Log uncertainties in the Question Ledger.  
6. Ask: does this improve **human connection / relationships**, or only story craft?
