## Decision rule (why a new volume)

| Question | Answer |
|---|---|
| Does this concept already exist? | Partial overlap with Connection Science (evidence) and BP-001 (exemplar method) |
| Chapter of Connection Science? | No — different job (field/leader map vs connection evidence ledger) |
| Appendix? | No — multi-domain program |
| Link only? | Insufficient — new institutional database |
| → New volume | **Yes** — genuinely new research domain |
