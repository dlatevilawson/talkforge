## How to use

1. Copy this file to `atos/product/research/cases/CASE-XXX-<short-slug>.md` (or fill the blank form below in a new case file).  
2. Complete **Basic Information** + sections **1–11**.  
3. Link the case from [cases/README.md](cases/README.md).  
4. Promote recurring insights into RP-001 cross-stream synthesis / LP counsel only after pattern across cases **and** check against other streams when claims get strong.  
5. Log uncertainties in the [Question Ledger](../../knowledge/working/questions.md).  
6. Remember: TalkForge optimizes for **connection and relationships**, not unforgettable ads.

## Field guidance (analyst notes)

### §1 Human Need
Prefer one primary need. Map to HBF-001 when possible. “Achievement” often maps to **Competence**; “Forgiveness” often to **Respect + Connection**.

### §2 Emotional Journey
Audience emotion ≠ character emotion (they can diverge). Name both if useful.

### §3 Curiosity Engine
Must be a question the audience holds — not a trivia quiz. If there is no sustained question, note that as a finding (some works use ritual/emotion over plot curiosity).

### §4 Transformation
If the work has no single protagonist (e.g. some ads), treat **the viewer’s invited identity** as the arc.

### §8 vs §7
§7 = craft techniques. §8 = what humans are like. Do not collapse them.

### §9 Applications
Must be specific enough to brief a designer or coach. Ban vague “be more emotional.”

### §10 Ethical Check
If you cannot name a misuse, you have not understood the power of the technique.
