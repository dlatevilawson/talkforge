## Statement

TalkForge is a new category — an AI Communication Gym. First-time users must **Welcome → Discover → Curiosity → Conversation → Training** before personalization. Post-signup opens a premium gym-floor Discover experience (what TalkForge is + interactive Machines), then two paths: **Start with Forge** (conversation) or **Explore Machines** (browse without commitment). Living Profile is not the first step; Forge learns through conversation; detailed profile is a later optional “Help Forge coach you better.”

---

## Why it matters

Inside-out architecture (profile → readiness → practice) made the first minutes feel like database setup. Outside-in discovery builds curiosity and trust so training feels exciting, not obligatory. Permanent principle: users experience transformation — never internal workings.
