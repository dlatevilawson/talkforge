## Statement

Every interaction should reduce unnecessary cognitive load so the member can focus on becoming more prepared.

---

## Why it matters

The invisible principle behind Constitution → Living Profile → Readiness → Homepage → Coach → Pedagogy → Craft:

| Mechanism | Load it removes |
|---|---|
| One mission above the fold | Choice overload |
| Readiness chooses what matters | Possibility overload |
| Pedagogy varies format | Cognitive fatigue from sameness |
| Anchoring great lines | Memory burden |
| Hold that thought | Interruption anxiety |
| Second opinions | Fear of missing a better choice |
| Evidence | Uncertainty |
| Adaptive coaching | Decision fatigue |

These are not isolated features. They solve one problem: **unnecessary cognitive load**.

Complements Craft Law #001:
- Craft asks: Does this feel more human / trustworthy / courageous?
- Design Principle #001 asks: Does this make thinking easier?
When both are yes, we are likely building the right thing.
